# User Stories

Reference the Writing User Stories final project guide in the course portal for more information about how to complete each of the sections below.

## Outline User Roles

- Student
- Teaching Assistant (TA)

## Draft User Stories

1. As a student, I want to see the due dates of my assignments, so that I can plan effectively for their delivery.

2. As a TA, I want to see the grades of my students, so that I can properly balance the attention I give them.

3. As a student, I want to see which topics are connected to which courses, so that I can ground my studies in specific disciplines and bodies of knowledge.

4. As a TA, I want to create study plans, so that I can tailor and administer them to students.

5. As a student, I want to mark up (comment on) study plans, so that I can enhance them with my TA.

6. As a TA, I want to create assignments with due dates, so that my students can organize their coursework.

7. As a TA, I want to edit or delete assignments, so that my students can keep their task lists accurate.

8. As a student, I want to mark assignments as completed, so that I can track my progress.

9. As a student, I want to prioritize assignments, so that I can focus on the most important tasks first.

10. As a student, I want to filter assignments by course, so that I can easily find tasks for a specific class.

11. As a student, I want to create and manage courses and link assignments to each course, so that I can organize my coursework and track assignments by class.
