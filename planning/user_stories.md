# User Stories

## Outline User Roles

1. **Trip Organizer:** A user who creates a trip and maintains its overall details, dates, and budget. Organizers can also participate in activities, voting, and expense tracking.
2. **Trip Member:** A user who joins a trip and contributes activity suggestions, votes, and expense records.

These roles apply to each trip: the same user can organize one trip and be a member of another.

## Draft User Stories

1. As a Trip Organizer, I want to create a trip with a destination and travel dates, so that my friends have a shared place to start planning.
2. As a Trip Organizer, I want to edit my trip’s details and budget, so that the group can see the latest travel information.
3. As a Trip Organizer, I want to delete a trip I created, so that canceled plans no longer appear as active trips.
4. As a Trip Organizer, I want to share a trip invitation code, so that my friends can join the correct trip.
5. As a Trip Member, I want to join a trip using an invitation code, so that I can participate in planning with my friends.
6. As a Trip Member, I want to view the trips I have joined and the members of each trip, so that I can find my plans and see who is coming.
7. As a Trip Member, I want to suggest an activity with a location, date, and estimated cost, so that the group can consider it for the itinerary.
8. As a Trip Member, I want to edit or delete my own activity suggestions, so that I can keep my contributions accurate as plans change.
9. As a Trip Member, I want to vote for an activity and remove my vote, so that I can express and update my preferences.
10. As a Trip Member, I want to view activity vote counts, so that I can see which ideas are popular with the group.
11. As a Trip Member, I want to view the itinerary by day and filter activities by date, so that I can quickly find the plans for a specific day.
12. As a Trip Member, I want to record shared expenses with the payer and amount, edit or delete my own entries, and view total spending against the trip budget, so that I can help keep the group’s expense records accurate.
